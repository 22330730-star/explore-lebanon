# Explore Lebanon - Frontend Project

## Project Description
A responsive React-based tourism web application built for CSCI426. It allows users to browse destinations, filter by region and category, read dynamic detail pages for specific landmarks, and curate a personalized "Saved Places" list.

## Setup Instructions
1. Clone the repository: `git clone <your-github-repo-url>`
2. Navigate into the directory: `cd explore-lebanon`
3. Install dependencies: `npm install`
4. Start the local server: `npm start`
5. The application will run on `http://localhost:3000`
